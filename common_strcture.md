# Kalaa Client Details

This repo contains standard client information used by Claude AI skills to generate content planners, captions, and reel scripts.

## How to use
- Each client has a separate `.md` file inside the `clients/` folder
- Follow the template below when adding a new client
- Fill all fields — the more detail, the better Claude's output
